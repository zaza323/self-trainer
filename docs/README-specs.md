# ملفات المتطلبات — ترتيب القراءة

1. `docs/PRD-v0.2.md` — الملف الرئيسي: ماذا نبني ولماذا، المتطلبات، البيانات، الشاشات، المراحل.
2. `docs/PRD-addendum-A-scoring.md` — كيف يُحسب كل شيء: الأدلة، الدرجات، البوابتان، المستويات، XP، والأمثلة المحلولة واختبارات المحرك.
3. `config/` — كل القيم القابلة للضبط:
   - `scoring.json` الأدلة والدرجات والبوابة الثانية
   - `support.json` مستويات الدعم والتدريب وفحص الإتقان
   - `game.json` المراحل والكثافة وXP والمساحة الشخصية والإنجازات
   - `customization.json` كتالوج الإعدادات والأقفال والمكافآت الواقعية واقتراحات التكيّف
   - `ai.json` حدود وتكلفة وظائف الذكاء الاصطناعي

## قواعد العمل مع Claude Code
- نفّذ **مرحلة واحدة في كل مرة** حسب القسم 14، وابدأ بالمرحلة 0 فقط.
- لا تنتقل لمرحلة قبل أن تمر معايير قبول التي قبلها.
- لا أرقام في الكود: كل قيمة من `config/`، وكل نص من `content/`.
- كل قراءة إعداد عبر `settings.effective(profileId, key)`.
- عند التعارض: الملحق (أ) للمعادلات، والملف الرئيسي لكل ما عداها.
